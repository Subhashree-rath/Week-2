# Employee Management System

## Overview
Console-based Java application to manage employees (Full-Time & Interns).

## Requirements
- Java 8+
- IntelliJ IDEA / Eclipse

## Setup
1. Copy project folder
2. Open IntelliJ
3. File → New → Project from Existing Sources
4. Select folder
5. Mark src as Sources Root
6. Set Java SDK (1.8)

## Run
Right-click Main class → Run

## Features
- Add Full-Time Employee
- Add Intern
- View Employees
- Search by ID
- Delete Employee
- Filter (Full-Time / Intern)

## Notes
- In-memory storage (no DB)
- Data lost after exit
