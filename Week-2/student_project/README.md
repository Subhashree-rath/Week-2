# Student Record Management System

## Overview
Simple Java console app for managing student records.

## Requirements
- Java 8+
- IntelliJ IDEA / Eclipse

## Setup
1. Copy project folder
2. Open IntelliJ
3. File → New → Project from Existing Sources
4. Select folder
5. Mark src as Sources Root
6. Set Java SDK (1.8)

## Run
Right-click Main class → Run

## Features
- Add Student
- View Students
- Search Student
- Delete Student

## Notes
- In-memory storage
- Data lost after exit
